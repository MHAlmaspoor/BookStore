# BookShop

A production-oriented microservices-based BookShop system
built with .NET 10.

## Architecture

- Clean Architecture
- Domain-Driven Design
- CQRS
- Domain Events
- Integration Events
- RabbitMQ
- Outbox Pattern
- PostgreSQL
- Redis

## Services

- ProductService
- IdentityService
- NotificationService

## BuildingBlocks

Shared infrastructure and messaging abstractions used
across services.
